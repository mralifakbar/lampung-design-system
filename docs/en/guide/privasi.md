# Privacy policy

https://lampung.kartadinata.app/docs/en/guide/privasi

This site is documentation only. There are no accounts, forms, ads or tracking cookies. This page explains the little data that is still involved when you open it. In effect since 17 November 2026.

## Who runs it

lampung.kartadinata.app is run by the contributors of Lampung Design System, a community open source project. It is not a government service and does not represent any agency. Privacy questions can be raised as a [GitHub issue](https://github.com/mralifakbar/lampung-design-system/issues).

## Data we keep

- **Theme choice.** If you pick light or dark, the choice is stored in your browser's `localStorage` under the key `lds-theme`. It never leaves your browser and you can clear it in the browser settings.
- **No cookies.** The site sets no cookies, so it shows no cookie consent banner.
- **No forms.** Forms in examples and docs are demos only. Nothing you type is sent anywhere.

## Third-party services

- **Cloudflare** serves this site. Like any web server, it receives your IP address, browser type and the page requested in order to deliver pages and block attacks. See the [Cloudflare privacy policy](https://www.cloudflare.com/privacypolicy/).
- **Visit statistics.** When enabled, we use Cloudflare Web Analytics, which counts visits without cookies or browser fingerprinting. We only see totals, such as visits per page.
- **Google Fonts** serves the Geist typeface. Your browser fetches font files from fonts.googleapis.com and fonts.gstatic.com, so Google receives your IP address. See the [Google Fonts privacy FAQ](https://developers.google.com/fonts/faq/privacy).
- **OpenStreetMap.** The map component examples load tiles from tile.openstreetmap.org, so OpenStreetMap's servers receive your IP address when you open those pages. See the [OSMF privacy policy](https://osmfoundation.org/wiki/Privacy_Policy).
- **Outbound links** to GitHub, npm and pub.dev follow those sites' own policies once you open them.

## Personal data in examples

Names, national ID numbers (NIK), phone numbers and addresses in the docs are made up and masked. If you find data that looks real, report it as a GitHub issue so it is removed right away.

## Your rights

Because we keep no data that identifies you, there is no personal data for us to show, change or delete. Your rights over data the providers above process apply under Indonesia's Personal Data Protection Law (Law No. 27 of 2022) and each provider's policy.

## Changes

If we add a service that processes data, this page is updated first. Its history is in the GitHub repository.
