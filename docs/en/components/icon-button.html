Icon button

A button that shows only an icon: 44 px target, 22 px glyph, round. It always has an aria-label and a tooltip with the same words.

Usage

Use it when

  • A well-known action in a toolbar, a card corner, a nav bar or a row where a text label would crowd: close, more options, share, bookmark, filter.
  • Several small actions sit together and each is recognizable by its icon alone (message actions: copy, retry, like).
  • The close button of a dialog, sheet, alert or lightbox.

Use something else when

  • The action is not obvious from an icon, or it is the main action of the view: use Button. Give it words. "Export" beats a lone download arrow nobody hovers.
  • The one creation action on a phone screen that floats over content: use Floating action.
  • The icon stays pressed to show a mode (bold, mute, pin): use Toggle.
  • It opens a list of related actions: use Dropdown menu. The trigger is still an icon button (more_horiz); the menu is the dropdown.
  • Copying a value with a visible confirmation: use Copy button.

Where it goes. Top right of cards, dialogs and sheets (close, more); at both ends of the phone nav bar; at the end of list rows; in toolbars grouped 2 to 4 together. On phones keep at least the 44 px target; never shrink icon-btn below it.

Examples

Anatomy

PartWhat it is
.icon-btnRequired. A <button> (or <a href> when it navigates). 44 by 44, round, transparent until hovered.
aria-labelRequired. The action in words ("More options", "Close").
.icRequired. The glyph, 22 px (19 px in --filled).
.tip-host + .tipRecommended. Wraps the button so the tooltip shows the same words after 500 ms of hover or on keyboard focus.

Variants and sizes

Class or attributeWhen
icon-btnTransparent; --bg-tint on hover, --bg-tint-strong while pressed.
icon-btn--filled36 px disc on --bg-recessed with 4 px margin, so the target stays 44.
icon-btn--accentAccent fill with the primary finish. Only for the floating action.

States

StateHow
hover--bg-tint background, on devices that can hover.
:activeSinks to scale(0.9) in 90 ms with --bg-tint-strong, back on --spring-snappy.
focusSystem focus ring (--focus, 2 px, offset 2 px); the tooltip shows too.
aria-pressed / aria-expandedWhen it toggles or opens something; for a lasting pressed look use toggle.
disabledPrefer hiding the action. If shown disabled, add disabled; there is no special style beyond the browser default, so pair it with a reason.

Motion and microinteractions

  • Press: transform: scale(0.9) on :active with a 90 ms duration; release returns on --spring-snappy over --d-snappy. Feedback starts on pointer down.
  • Background color changes over --d-fast on --ease-standard.
  • Tooltip: waits 500 ms, then fades in over --d-fast and rises on --spring-snappy; leaves at once (100 ms on --ease-exit).
  • When the glyph changes meaning (play to pause), use icon swap inside the button.

Accessibility

  • <button type="button"> with aria-label; the icon span is aria-hidden="true".
  • The label names the action and, when there are many on a page, the object: "More options for Lab report 3".
  • The tooltip is supplementary; it uses role="tooltip" and shows on :focus-within, so keyboard users see it too.
  • Target is 44 by 44; do not set a smaller width or height.

Do and don't

check_circleDo

  • Use only icons whose meaning is common: close, more, share, search, settings.
  • Repeat the aria-label words in the tooltip.
  • Group related icon buttons with 0 to 4 px between them; the round hover shapes already separate them.

cancelDon't

  • Use an icon button for the primary action of a form or page.
  • Shrink it to 32 px to fit a dense row; use a btn--sm with text instead.
  • Use icon-btn--accent anywhere other than a floating action.
