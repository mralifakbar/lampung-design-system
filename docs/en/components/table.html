Table

Rows of records compared by the same columns, in a .table-box that scrolls sideways when it must. A real <table> by default, .table--wrap for text, and the .dt grid when a template repeats rows.

Usage

Use it when

  • Comparing many records by the same attributes: courses by code, credits and seats; payments by date, amount and status.
  • Data people sort, scan down a column or select rows from (grade books, rosters, invoices).
  • A two-column text table of rules or definitions (.table--wrap).

Use something else when

  • Items with one or two facts each, especially on phones: use List.
  • The details of one record: use Key-value.
  • A few summary figures: use Stat row.
  • The shape of the numbers matters more than the values: use Bar chart.
  • A hierarchy of folders or sections: use Tree.

Where it goes. In the content column, full width of it, inside .table-box (ring, radius, horizontal scroll). On phones keep the first column meaningful and let the box scroll, or show the same data as a list when people need only one or two columns. Put filters and actions above it, pagination under it.

Anatomy

PartWhat it is
.table-boxRequired. The surface: white, ring, large radius, overflow: auto so wide tables scroll inside it.
table.tableRequired. Full width, 14 px text; th is a 40 px header on the quiet fill, td rows are 52 px with a hairline above.
th > button (.is-sorted, .is-desc)A sortable header: an arrow icon that turns when sorted descending.
.numOn th and td: right-aligned tabular figures. Every numeric column.
td.strongThe cell that names the row (strong, medium weight).
tr.is-selectedA selected row on the accent tint.
.table--wrapText tables: cells wrap and grow, top-aligned; the first column takes 32 %.
.dt[role=table] > .dt__row[role=row] > .dt__cellThe grid table: rows of cells, for templates that repeat rows freely. .dt__head for the header row, .dt__sort for sortable headers. Set grid-template-columns on .dt__row per table; it is at least 720 px wide.

Variants and sizes

Class or attributeWhen
tableOne-line cells, 52 px rows. Records and numbers.
table--wrapWrapping, top-aligned cells for text.
dtGrid table with ARIA roles, when a template engine repeats row components; cells ellipsize instead of wrapping.

States

StateHow
hoverBody rows tint --bg-tint (60 ms).
sorted.is-sorted on the header button (arrow at full opacity), .is-desc turns it; set aria-sort on the th (or the columnheader cell).
selectedtr.is-selected / .dt__row.is-selected, with a checked checkbox in the first column and a selection bar for bulk actions.
loadingSkeleton bars in each cell, keeping the header.
emptyOne row spanning all columns with an empty state, keeping the header and filters.

Motion and microinteractions

  • Row hover: background over 60 ms linear, near instant so scanning never lags.
  • The sort arrow turns 180 degrees on --spring-smooth (--d-smooth); its opacity changes over --d-fast.
  • Re-sorting does not animate rows; the new order appears at once.

Accessibility

  • Prefer a real <table> with <th>; with .dt, give every element its role (table, row, columnheader, cell) and the table an aria-label.
  • Sortable headers are <button>s inside the header; put aria-sort="ascending|descending" on the header cell of the sorted column only.
  • The scrolling .table-box should be reachable by keyboard when it overflows: add tabindex="0" and an aria-label, or make sure a focusable element inside it scrolls it.
  • States in cells use words (badge), not color alone.

Do and don't

check_circleDo

  • Right-align every numeric column with .num, header included.
  • Make the first column the one that names the row.
  • Keep the header and filters visible in the loading and empty states.

cancelDon't

  • Use a table for layout or for a single record.
  • Squeeze a wide table onto a phone; let it scroll or switch to a list.
  • Add zebra stripes, vertical rules or a custom header color.

Behavior and code

Plain HTML. None. Sorting, selection and paging are app logic: re-render the rows and update .is-sorted, .is-desc and aria-sort.
