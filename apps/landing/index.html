Dokumentasi Komponen Contoh GitHub
Bahasa Indonesia, ID English, EN
Tema gelap

Sistem desain terbuka untuk situs dan aplikasi layanan publik.

Lampung Design System (LDS) berisi token, komponen, dan panduan berbahasa Indonesia, supaya pemerintah daerah, warga Lampung, dan siapa pun bisa membangun situs dan aplikasi dengan cepat dan tampilan yang seragam.

Mulai membangun codeLihat di GitHub

Gratis dengan lisensi MIT. Dibuat oleh komunitas, bukan oleh Pemerintah Provinsi Lampung.

Warna, tipografi, jarak, sudut, bayangan, dan gerak tersimpan di tokens.json, masing-masing dengan nilai terang dan gelap. Satu perintah menulis variabel CSS, modul JavaScript bertipe, kelas Dart, dan tema shadcn/ui.

downloadPemasangan

Pasang di proyek Anda.

Pilih kerangka kerja, salin perintahnya, lalu jalankan di folder proyek. Panduan lengkap untuk tiap kerangka kerja ada di dokumentasi.

Terminal
npx lampung-ds@latest init -t next

Jalankan di folder proyek Next.js yang sudah ada.

Terminal
npx lampung-ds@latest init -t vite

Jalankan di folder proyek Vite yang sudah ada.

Terminal
npx lampung-ds@latest init -t start

Jalankan di folder proyek TanStack Start yang sudah ada.

Terminal
npx lampung-ds@latest init -t react-router

Jalankan di folder proyek React Router yang sudah ada.

Terminal
npx lampung-ds@latest init -t astro

Jalankan di folder proyek Astro yang sudah ada.

Terminal
laravel new my-app
cd my-app
npx lampung-ds@latest init -t laravel

Proyek Laravel sudah ada? Lewati dua baris pertama dan jalankan baris terakhir di folder proyek.

Terminal
npx lampung-ds@latest init -t html

Tanpa pemasangan, tautkan CSS dari CDN di dalam <head>:

index.html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/lampung-design-system@0/css/lds.css">
Terminal
flutter pub add lampung_design_system

Jalankan di folder proyek Flutter. Paketnya berisi token, tema, dan widget.

paletteWarna

Dua warna yang berangkat dari Lampung.

Keduanya terinspirasi dari lambang provinsi, mahkota siger, dan kain tapis. Ini inspirasi, bukan pemakaian resmi: LDS tidak memakai lambang daerah, dan warnanya bukan warna resmi pemerintah.

Hijau Lampung #0B6E4F

Terinspirasi dari hijau pada lambang Provinsi Lampung. Dipakai untuk tombol utama, pilihan yang aktif, dan tautan.

Emas Siger #C9952B

Terinspirasi dari mahkota siger dan benang emas kain tapis. Dipakai untuk identitas dan hiasan, tidak untuk tombol dan tidak sebagai teks di atas putih.

Aksara Lampung untuk kata Lampung. Di LDS, aksara hanya hiasan dan selalu didampingi bacaan Latin.
