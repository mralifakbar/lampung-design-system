Ranked bars

Rows of a label, a horizontal bar and its value, sorted longest first: top sources, top pages, best scores. Long labels stay readable because they sit beside (or inside) the bar instead of under it, and every row shares one grid so bars and values line up.

Usage

Use it when

  • Ranking 3 to 10 named things by one value: traffic sources, pages, products, students, regions.
  • Category names are long or many ("Partner schools", "/courses/sql-basics"), which vertical bars would have to rotate.
  • A leaderboard: rank, who, and the score, with the bar as a quick sense of the gaps.

Use something else when

  • Categories that have an order of their own (weekdays, months): use Bar chart.
  • Progress of each item toward its own goal: use Target bar.
  • Parts that add up to one whole: use Percentage bar.
  • Many records compared on several attributes: use Table.
  • Steps of a flow where each keeps a share of the one before: use Funnel.

Where it goes. In a chart card, half width on a dashboard. Under 480 px the bar moves under its label and value, full width. Set --label-w on .hbars to change the label column (default 140 px).

Examples

Anatomy

PartWhat it is
.hbarsRequired. The grid: label column, bar column, value column. role="list" when the rows are a ranking.
.hbarRequired. One row; a subgrid of .hbars, so values line up across rows. .is-top marks the leader.
.hbar__labelRequired. The name; may start with .hbar__rank, .hbar__media (an icon tile or .avatar) and carry a .hbar__sub line.
.hbar__track > .hbar__fillRequired. 10 px track; --v sets the fill as a percent of the largest value.
.hbar__valRequired. The value, tabular; may hold a trend delta.
.hbars--insideVariant. 36 px tint bars with the label inside, for long labels in narrow cards.
.hbars--mutedVariant. Every bar but .is-top recedes to the tint.

Variants and sizes

Class or attributeWhen
.hbar__mediaAn icon tile (sources, products) or an .avatar (people) before the name.
.hbar__rankPosition number for leaderboards.
.hbar__subA second line under the name: course, category, visits.
.hbars--insideLabel inside a 36 px tint bar; the leader gets a 3 px accent edge.
.hbars--mutedOnly the leader in the series color.
--label-wWidth of the label column on .hbars.

States

StateHow
hoverThe row under the pointer stays, the others fade to 55 %.
data changeSet new --v values: fills move over 480 ms on --ease-inout. Re-sort only after the move, or not at all while someone reads.
loadingFive .skel rows: a label block and a 10 px strip.
emptyKeep the title; one line saying no visits came in for the period.

Motion and microinteractions

  • First view (data-lds-grow): fills grow from zero on --spring-smooth (560 ms), 35 ms apart from the top row.
  • Value changes: width over --d-considered on --ease-inout, from the current width.
  • Hover fade over --d-fast. Reduced motion: values switch in 120 ms, no stagger.

Accessibility

  • Use role="list" on .hbars and role="listitem" on rows when the order is the point; the label and value are real text, so the list reads "Search, 4,210, 12% up".
  • The bar is decoration on top of the value; no extra label is needed.
  • A delta carries "up" or "down" in .sr-only text.

Do and don't

check_circleDo

  • Sort longest first; say the period in the subtitle.
  • Scale every bar to the largest value in the set, or to a fixed maximum such as 100 for scores.

cancelDon't

  • Give every bar its own color.
  • Cut the bar axis above zero.
  • Show more than ten rows; add a link to the full table instead.

Behavior and code

Plain HTML. Optional: data-lds-grow on .hbars (or its card) plays the first-view entrance. Values change by setting --v on each fill.
