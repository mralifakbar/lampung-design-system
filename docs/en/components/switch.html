Switch

An on and off control for a setting that applies the moment it is flipped, with no Save button. The thumb stretches while held and travels on a spring.

Usage

Use it when

  • A setting that takes effect immediately: notifications, sounds, dark mode, show timer during exams.
  • Settings lists on phones (a small switch at the end of a list row).
  • Turning a feature on with a short explanation under the label (.switch__text with small).

Use something else when

  • A choice saved later with a form: use Checkbox. Switches imply instant effect.
  • Choosing between two named states (Light, Dark; List, Grid): use Segmented control.
  • A pressed state on a toolbar button (bold, mute): use Toggle.
  • Agreeing to terms: use Checkbox.
  • Several filters that apply together: use Chips.

Where it goes. In settings: one per line in a column, or at the end of a .lrow in an inset list on phones (use switch--sm there). On wide screens keep the label close to the switch; never put the switch at the far right of a very wide row with the label at the far left.

Examples

Anatomy

PartWhat it is
label.switchRequired. Wraps the input, the track and the text; the whole row toggles. A <span class="switch"> when the row (label.lrow) is the label.
input[type=checkbox][role=switch]Required. The native checkbox announced as a switch, invisible over the track.
.switch__trackRequired. 51 by 31, gray when off, accent when on. aria-hidden.
.switch__thumbRequired. The 27 px white thumb inside the track.
.switch__textOptional. Label text with a small second line that explains the effect.

Variants and sizes

Class or attributeWhen
switch (default)51 by 31, for settings pages and forms.
switch--sm38 by 23, for list rows and dense panels.

States

StateHow
on (checked)Accent track (fades in over the gray), thumb moved right.
:active (held)The thumb widens by 6 px (4 px small) toward its destination.
.is-flipAdded by the JS on every change: the thumb stretches once as it lands.
focus-visibleFocus ring around the track.
disabledTrack at 40 % opacity; say why in the small line.

Motion and microinteractions

  • Travel: the thumb moves with transform on --spring-smooth (560 ms); the accent layer fades in --d-standard (240 ms) on --ease-standard, the track color in --d-fast.
  • Hold: width grows by 6 px on --spring-snappy (360 ms); releasing mid-travel retargets from where it is.
  • Landing: lds-stretch scales the thumb to 1.16 by 0.94 and back in 340 ms on --ease-standard, whatever changed it (tap, key, label click, code).
  • With a bell icon inside the label, it rings once when turned on (bell).
  • Reduced motion: transitions become 120 ms linear and the stretch is skipped.

Accessibility

  • <input type="checkbox" role="switch"> is announced as "switch, on" or "off"; Space toggles. Never build a switch from a div.
  • The visible text is the name. In a list row, the label.lrow is the label for the input inside it.
  • The change applies at once; if it can fail (a server call), revert the switch and explain in a toast.

Do and don't

check_circleDo

  • Label the setting, not the action: "Class reminders", not "Turn on reminders".
  • Apply immediately and show the result when it is not obvious.

cancelDon't

  • Put switches in a form that has a Save button.
  • Change the label text with the state ("On" or "Off"); the switch shows that.
  • Use a switch for two named options; use a segmented control.

Behavior and code

Plain HTML. Automatic for every .switch input: on change it adds .is-flip for the landing stretch (and rings a .bell inside when turned on). No data-lds-* needed.

React. From lampung-design-system/react.

import { Switch } from 'lampung-design-system/react';

<Switch checked={reminders} onChange={setReminders} sub="15 minutes before each class starts">
  Class reminders
</Switch>
<Switch size="sm" checked={haptics} onChange={setHaptics}>Haptic feedback</Switch>
