Select

Tombol berbentuk kolom yang membuka daftar opsi di bawahnya dan menampilkan yang dipilih. Untuk satu pilihan dari daftar tetap yang terlalu panjang untuk ditampilkan sebagai radio; jika orang perlu mengetik untuk menemukannya, pakai combobox.

Penggunaan

Pakai saat

  • Satu nilai dari daftar tetap sekitar 6 sampai 30 opsi: jenjang pendidikan, semester, kategori ujian, provinsi saat daftarnya pendek.
  • Ruang terbatas, sehingga semua opsi tidak bisa terlihat (bilah filter, baris formulir).
  • Opsi butuh baris keterangan kedua di dalam daftar (.select__text dengan small).

Pakai yang lain saat

  • Dua sampai lima opsi yang muat di layar: pakai Radio. Opsi yang terlihat lebih cepat dibandingkan dan cukup sekali ketuk.
  • Setiap opsi butuh deskripsi, harga, atau badge: pakai Radio card.
  • Beralih antartampilan dari konten yang sama saat itu juga: pakai Segmented control.
  • Daftar panjang (kota, sekolah, lebih dari sekitar 30) atau opsi dari server: pakai Combobox. Orang mengetik untuk menemukan alih-alih menggulir.
  • Beberapa nilai sekaligus: pakai Chips. Atau checkbox di formulir, atau tag input untuk nilai bebas.
  • Daftar aksi (Urutkan, Ekspor, Hapus): pakai Dropdown menu. Select menyimpan nilai; menu menjalankan perintah.
  • Berpindah antarbagian atau halaman: pakai Tabs. Atau sidebar saat tujuannya banyak.

Letaknya. Di formulir seperti text field, dengan label di atas. Di bilah filter pada layar lebar dengan lebar tetap (sekitar 220 px). Daftar terbuka di alur halaman di bawah pemicu, selebar pemicu; di ponsel daftar lebih dari sekitar 8 opsi lebih nyaman dibaca di sheet.

Contoh

Anatomi

BagianFungsinya
.selectWajib. Pembungkus berposisi, selebar kolomnya. data-lds-select untuk perilaku HTML biasa.

.select__valueWajib. Label terpilih (atau placeholder), dipotong dengan elipsis saat panjang.

li.menu__item[role=option]Wajib. Satu opsi dengan data-value dan aria-selected; .is-selected menandai yang dipilih. Taruh .select__text dengan small di dalamnya untuk baris kedua.

Gerak dan mikrointeraksi

  • Daftar tumbuh dari pemicu: opacity dalam --d-fast (160 ms) dengan --ease-enter dan scale(0.96) translateY(-4px) ke posisi diam dengan --spring-smooth (560 ms), titik asal kiri atas.
  • Ia menutup lebih cepat daripada membuka: opacity dan transform dalam --d-exit (180 ms) dengan --ease-exit, lalu visibility berganti. Membuka lagi di tengah penutupan berbalik dari posisinya saat itu.
  • Chevron berputar 180 derajat dengan --spring-smooth. Sorotan baris berganti dalam 60 ms linear agar berpindah dengan panah terasa langsung.
  • Reduced motion: menu memudar masuk 120 ms linear tanpa skala atau perpindahan.

Aksesibilitas

  • Pemicu adalah <button type="button"> (di dalam formulir tombol polos akan mengirim) dengan aria-haspopup="listbox", aria-expanded, dan nama dari label terlihat lewat aria-labelledby.
  • Tombol: Bawah, Atas, Enter, atau Spasi membuka; Bawah dan Atas berpindah; Home dan End melompat; Enter atau Spasi memilih; Escape menutup dan menjaga fokus di pemicu; Tab menutup; mengetik huruf melompat ke kecocokan pertama (jeda 700 ms).
  • JS memberi listbox sebuah id, menyetel aria-controls, dan memindahkan aria-activedescendant pada pemicu; opsi membawa aria-selected.
  • Tidak ada nilai formulir bawaan: saat lds:change tulis nilainya ke input tersembunyi, atau baca dari state Anda.

Lakukan dan hindari

check_circleLakukan

  • Tulis placeholder yang menyebut aksinya ("Pilih jenjang"), dan tampilkan bawaan terpilih jika memang jelas benar.
  • Urutkan opsi sesuai harapan orang (jenjang, waktu, abjad), bukan berdasarkan id basis data.
  • Pakai baris kedua (small) untuk kode atau keterangan singkat, bukan teks promosi.

cancelHindari

  • Memakai select untuk dua atau tiga opsi; tampilkan radio atau segmented control.
  • Menaruh aksi atau tautan di dalam listbox.
  • Memberi gaya <select> bawaan agar tampak seperti ini; pakai .select (sistem tidak memberi gaya select bawaan).

Perilaku dan kode

HTML biasa. data-lds-select pada .select: membuka dan menutup listbox, menangani tombol di atas, menutup saat pointer di luar, menulis label terpilih ke .select__value, dan memicu lds:change dengan { value, label } pada pembungkus (nilai dari data-value).

React. Dari lampung-design-system/react.

import { Select } from 'lampung-design-system/react';

<span className="field__label" id="level-label">Jenjang pendidikan</span>
<Select
  labelledBy="level-label"
  value={level}
  onChange={setLevel}
  placeholder="Pilih jenjang"
  options={[
    { value: 'd3', label: 'Diploma', sub: 'D-III' },
    { value: 's1', label: 'Sarjana', sub: 'S-1, D-IV' },
  ]}
/>
