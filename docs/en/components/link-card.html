Link card

A grid of destinations on the quiet fill: each card is one link with an eyebrow, a title, a line of detail and a foot whose chevron leans toward where it goes.

Usage

Use it when

  • A hub page that sends people to a few places of equal weight: my courses, the question bank, transcripts, settings.
  • Each destination deserves a sentence or a status ("3 tasks open", "Updated today").
  • Two to about nine destinations; the grid fills columns of at least 300 px.

Use something else when

  • Many destinations, or ones that only need a name: use List. Linked rows (a.lrow) with a chevron.
  • The one next step for this person: use Spotlight.
  • A box that shows content and has several actions inside: use Card.
  • App navigation that is always there: use Sidebar. Or a top nav or the phone tab bar
  • Choosing an option in a form: use Radio card.
  • Key figures: use Stat row.

Where it goes. Inside a section on hub and dashboard pages, full width of the column. The grid uses auto-fill with 300 px minimum columns: one column on phones, two or three on wide screens.

Examples

Anatomy

PartWhat it is
.link-gridRequired. The grid, 12 px gaps.
a.link-cardRequired. The whole card is one <a href> (or a <button> for an in-page action). Quiet fill, large radius, 18 by 20 padding.
.link-card__eyebrowOptional. Caption with a small icon: the kind of destination.
.link-card__titleRequired. The destination name, headline size.
.link-card__bodyOptional. One line of detail.
.link-card__footOptional. Status at the bottom (pushed down so feet line up) with a .lrow__chev chevron at the end.

States

StateHow
hover (fine pointer)Background deepens to --bg-tint-strong; the chevron moves 3 px right and turns accent.
:activeThe card sinks to 0.985 in --d-instant (120 ms).
focus-visibleThe system focus ring around the card.

Motion and microinteractions

  • Hover: background in --d-fast (160 ms) on --ease-standard; the chevron translateX(3px) on --spring-snappy (360 ms). Only on devices with hover and a fine pointer, so touch never sticks in the hover state.
  • Press: scale(0.985) (wide targets barely sink), back on --spring-snappy. See press feedback.
  • Cards in a grid that loads may enter with list stagger once; never on every visit to the page.
  • Reduced motion: transitions become 120 ms linear; no travel.

Accessibility

  • One link per card: the whole card is the <a>, so its name is the text inside. Do not nest other links or buttons in it.
  • Keep the title first in the reading order after the eyebrow, and short, so the link name starts with the destination.
  • The chevron is decorative (aria-hidden).

Do and don't

check_circleDo

  • Write the foot as a fact about the destination ("3 tasks open").
  • Keep cards in a grid of the same kind; mix kinds in separate sections.

cancelDon't

  • Add images, shadows or borders to make one card stand out; use a spotlight for the one that matters.
  • Put buttons inside a link card.
  • Make a link card that is not a link (a div gets no hover or press).
