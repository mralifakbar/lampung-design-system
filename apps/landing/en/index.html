An open design system for public service websites and apps.

Lampung Design System (LDS) gives you tokens, components and guides written in Indonesian and English, so local governments, people in Lampung and anyone else can build websites and apps quickly with a consistent design.

groupsWho it is for

For teams that build services for citizens.

Anyone may use it, for government, business or personal projects.

account_balance

Local governments and agencies

Agency websites, service portals and internal dashboards that look the same across every office, without commissioning a design from scratch for each project.

code

Developers

Install with one command. Components are plain CSS classes, and their behavior is one optional script that works in any framework.

Designers

Color, type, spacing and motion are stored as tokens, with light and dark values whose contrast has already been computed.

Small businesses and communities

inventory_2What is included

What you get.

One npm package for the web, one pub.dev package for Flutter, and documentation in Indonesian and English.

tuneTokens

One token file for CSS, JavaScript and Flutter.

Color, type, spacing, radius, shadows and motion live in tokens.json, each with a light and a dark value. One command writes CSS variables, a typed JavaScript module, a Dart class and a shadcn/ui theme.

  • check_circleChange the accent once and the website and the Flutter app follow.
  • check_circleSprings are exported as curves, so motion feels the same on the web and on phones.
css/tokens.css

widgets

170+ components

Buttons, forms, data tables, calendars, maps and charts. Every component has a documentation page in Indonesian and English: when to use it, markup, states and accessibility.

rocket_launch

A CLI for eight frameworks

lampung-ds init sets up Next.js, Vite, TanStack Start, React Router, Astro, Laravel, plain HTML and Flutter.

dark_mode

Dark mode

Every color has its own dark value. The theme can follow the person's choice or the device setting.

contrast

WCAG 2.2 AA contrast

The contrast of every text color pairing is computed in light and dark: body text at least 4.5:1, control edges at least 3:1.

text_fields

Aksara Lampung accents

The Lampung script appears as a quiet ornament, always with the Latin reading next to it or for screen readers.

menu_book

Skills for AI agents

AI coding agents read the LDS component catalog and rules before they write UI, then use the components that already exist.

downloadInstall

Add it to your project.

Pick your framework, copy the command and run it in the project folder. The full guide for each framework is in the documentation.

Terminal
npx lampung-ds@latest init -t next

Run it in the folder of an existing Next.js project.

Terminal
npx lampung-ds@latest init -t vite

Run it in the folder of an existing Vite project.

Terminal
npx lampung-ds@latest init -t start

Run it in the folder of an existing TanStack Start project.

Terminal
npx lampung-ds@latest init -t react-router

Run it in the folder of an existing React Router project.

Terminal
npx lampung-ds@latest init -t astro

Run it in the folder of an existing Astro project.

Terminal
laravel new my-app
cd my-app
npx lampung-ds@latest init -t laravel

Already have a Laravel project? Skip the first two lines and run the last one in the project folder.

Terminal
npx lampung-ds@latest init -t html

No install? Link the CSS from the CDN inside <head>:

index.html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/lampung-design-system@0/css/lds.css">
Terminal
flutter pub add lampung_design_system

Run it in your Flutter project folder. The package holds the tokens, the theme and the widgets.

paletteColor

Two colors that start in Lampung.

Both are inspired by the provincial emblem, the siger crown and tapis cloth. They are inspiration, not official use: LDS does not use the regional emblem, and these are not official government colors.

Hijau Lampung #0B6E4F

Lampung green, inspired by the green of the Lampung provincial emblem. Used for the main button, the current selection and links.

Emas Siger #C9952B

Siger gold, inspired by the siger crown and the gold thread of tapis cloth. Used for identity and ornament, never for buttons and never as text on white.

The word Lampung in aksara Lampung. In LDS the script is only ornament and always comes with its Latin reading.
