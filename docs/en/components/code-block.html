Code block

Preformatted code on the quiet fill with a bar for its name and a copy action. Three quiet token colors, horizontal scroll, no line wrapping.

descriptionView as Markdown

Usage

Use it when

  • Code, commands or configuration the reader copies: an install line, an API call, a snippet in documentation.
  • Output a person needs to read exactly (a log excerpt, a generated key).

Use something else when

  • A short code word inside a sentence: use Inline code.
  • A tool the assistant ran, with its input and output: use Tool call.
  • A quotation from a source: use Quote.
  • Long-form text: use Prose.

Where it goes. In the reading column, full width of it, between paragraphs of prose or under a section heading. On phones it keeps its width and scrolls sideways; it never wraps code.

Examples

Anatomy

PartWhat it is
.codeblockRequired. Quiet fill, 14 px radius, clips its content.
.codeblock__barA 40 px bar with the file name or language on the left and a copy button on the right.
preRequired. 12.5 px mono, 20 px line height, 14/16 px padding, scrolls horizontally.
.k / .s / .cToken colors: keys and keywords (accent), strings (success), comments (muted).

Variants and sizes

Class or attributeWhen
with barA name and a copy action. The default for anything copyable.
without barJust pre inside .codeblock, for output to read.

States

StateHow
copiedThe copy button swaps its icon to check and its label to "Copied" for a moment (copy button).

Motion and microinteractions

  • Only the copy button moves: the icon swap on --spring-snappy. The block itself is still.

Accessibility

  • Use <pre><code> so the content is announced as code and whitespace is kept.
  • The copy button has a visible label ("Copy"); its confirmation changes the label text, which is announced when focus is on it.
  • Token colors are not meaningful on their own; contrast stays at body level on the fill.
  • Long lines scroll inside pre; make the block focusable (tabindex="0") when it overflows so keyboard users can scroll it.

Do and don't

check_circleDo

  • Name the file or the language in the bar.
  • Keep snippets short and runnable.

cancelDon't

  • Wrap code lines or shrink the font to fit.
  • Use a dark theme block inside the light theme.
  • Show code as an image.

Behavior and code

Plain HTML. Optional. The copy button uses data-lds-copy="text" (see copy button).
