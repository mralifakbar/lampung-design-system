Key-value

Label and value pairs that describe one thing: a payment, an exam registration, a profile. .kv rows in a <dl>, inside a card or in their own .kv-list box.

Usage

Use it when

  • The details of one record: fee, due date and status of a payment; seat, room and time of an exam.
  • A summary before a confirm ("Review your registration").
  • Facts about a page's subject in a side panel.

Use something else when

  • Several records compared by the same attributes: use Table.
  • A few big numbers that summarize a page: use Stat row.
  • Rows that navigate to change each value: use List. Use .lrow__value with a chevron.
  • The values are editable: use Form layout.
  • Events with dates in order: use Timeline.

Where it goes. Inside a card under its title, in a side panel, in a dialog before a confirm, or alone as a .kv-list box in the content column. Label left, value right on every screen size; switch to .kv-list--stack when values are long sentences or names.

Examples

Anatomy

PartWhat it is
dlRequired. The list of pairs.
.kvRequired. A div row: label left, value right, 44 px minimum, hairline between rows. No padding of its own, so it fits in cards and rows.
.kv > dtThe label: subtle text.
.kv > ddThe value: strong, right-aligned, tabular figures; long values wrap.
dl.kv-listA box of its own: quiet fill, large radius, 16 px side padding, 48 px rows, values in semibold.
.kv-list--baseWhite box with a hairline ring, for use on the quiet fill.
.kv-list--stackLabel above, value below, left-aligned: for long values (titles, legal names, dates in words).

Variants and sizes

Class or attributeWhen
kvBare rows, no box. Inside cards, dialogs and list rows.
kv-listIts own filled box; values semibold.
kv-list--baseWhite with a ring, for filled surfaces.
kv-list--stackLabel above value, left-aligned, for long values.

States

StateHow
missing valueWrite "Not set" in the value, never leave it blank or use a dash.
loadingA skeleton bar in each dd, the labels already shown.

Motion and microinteractions

  • None at rest. When a value changes in place, use text morph for words or a rolling number for figures.

Accessibility

  • Use <dl> with <div class="kv"><dt>…</dt><dd>…</dd></div>: screen readers pair each term with its value.
  • Keep labels short and specific ("Due", not "Date 2").
  • Values that are states use words (a badge), not color alone.

Do and don't

check_circleDo

  • Order rows by what the person checks first.
  • Use --stack as soon as values wrap to two lines.
  • Format numbers and dates the same way across the product.

cancelDon't

  • Build key-value rows from a table or from two div columns.
  • Put actions inside values; put one action under the box.
  • Mix stacked and side-by-side rows in one box.
