Menubar

A row of command menus (File, Edit, View) for a desktop-style editor. Each button opens a dropdown menu of commands with their shortcuts.

Usage

Use it when

  • A document or content editor on wide screens with many commands people learn by shortcut: a lesson editor, a question bank, a report builder.
  • Commands group naturally into four to six menus.

Use something else when

  • A handful of actions on one object: use Dropdown menu. One "more" button with a menu.
  • Site or app navigation between pages: use Top nav.
  • Formatting buttons people press often (bold, italic, align): use Button group.
  • Searching every command by name: use Command palette.

Where it goes. At the top of the editor surface, under the page title and above the document, left-aligned. Hide it on phones: put the few commands that matter in a dropdown menu or a sheet.

Examples

Anatomy

PartWhat it is
.menubar[role=menubar]Required. The bordered row with aria-label; positioned so menus can hang from it.
.menubar__btnRequired. A 32 px menu button with role="menuitem", aria-haspopup="menu", aria-expanded and data-lds-menu naming its menu.
.menuRequired. The dropdown menu for each button, placed in a position: relative wrapper.
.menu__item kbdThe shortcut, right-aligned and muted.

States

StateHow
hoverStrong tint behind the button.
aria-expanded="true"The button keeps the tint while its menu is open.
menu openSee dropdown menu: grows from the top left of its button.

Motion and microinteractions

  • Button tint eases over --d-instant (120 ms).
  • Menus enter with opacity over --d-fast and scale from 0.96 and -4 px on --spring-smooth; they leave over --d-exit (180 ms) on --ease-exit. Opening another menu closes the first at once.
  • Reduced motion: menus fade only, no scale.

Accessibility

  • role="menubar" with aria-label; each button role="menuitem" with aria-haspopup="menu" and aria-expanded.
  • Down arrow on a button opens its menu and focuses the first item; Up and Down move inside; Escape closes and returns focus to the button.
  • Show shortcuts in kbd and make them work; a shortcut that is only displayed is a lie.
  • Left and Right between menubar buttons are not wired by the script; add them in your code (move focus to the previous or next .menubar__btn, and open its menu if one was open).

Do and don't

check_circleDo

  • Use the conventional order: File, Edit, View, then domain menus, Help last.
  • Mirror every menubar command in the command palette.

cancelDon't

  • Use a menubar for navigation between pages.
  • Show it on phones.
  • Put a single command directly on the bar as a button; everything on the bar opens a menu.

Behavior and code

Plain HTML. Each .menubar__btn uses the menu hook: data-lds-menu="menuId" toggles .is-open on the menu and aria-expanded on the button, Down arrow opens it, Up/Down move between items, Escape or a click outside closes it. closeMenus() closes it from code.
