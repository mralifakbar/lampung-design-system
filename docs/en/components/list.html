List

The inset grouped list: rows on one surface, separated by hairlines that start where the text starts. The default for any list of things, instead of a stack of cards.

descriptionView as Markdown

Usage

Use it when

  • Any collection of similar items the person scans or opens: services, messages, settings, payments, files.
  • Navigation rows that lead somewhere (a.lrow with a chevron) or act (button.lrow).
  • Settings, each row a label with its value, a switch or a chevron.
  • Numbered steps to follow (.lrow--num) or a checked list of requirements or what is included (.lrow--check).

Use something else when

  • Items are compared across several attributes (columns): use Table.
  • Label and value pairs describing one thing: use Key-value.
  • Each item is a rich subject with media and its own actions: use Card.
  • A grid of destinations on a landing or overview page: use Link card.
  • Nested folders or a hierarchy: use Tree.
  • Events in time order with a connecting line: use Timeline.
  • The person picks one option from the rows: use Radio card.
  • The steps of a flow the person is in right now: use Steps.
  • A long list where only the first few matter: use Show more.

Where it goes. In the content column, full width of it, on phones edge to edge inside the page padding. A .list__header above names the group and a .list__footer below explains it. On the canvas use the default white list; on a quiet-fill panel use .list--fill.

Examples

Anatomy

PartWhat it is
.listRequired. The surface: white with a hairline ring and the large radius, clipping its rows. Use div, or ul/ol with li.lrow rows.
.list--fillThe quiet fill instead of white, without the ring.
.lrowRequired. A row: 48 px minimum, 16 px side padding, 12 px gap. Rows must be direct siblings so the hairline (.lrow + .lrow) draws.
a.lrow / button.lrowA row that navigates or acts. Highlights on press; linked rows tint on hover and lean their chevron 2 px forward.
.lrow--icon + .lrow__icon > .icA 30 px colored square with a white filled glyph; the hairline then starts after the icon (58 px).
.lrow__body > .lrow__title + .lrow__subRequired. Title (15 px) and an optional second line (13 px, subtle).
.lrow__valueA trailing value (15 px, subtle): a setting, a time, an amount.
.lrow__chevThe trailing chevron_right on rows that navigate.
.lrow--num > .lrow__numNumbered row: a 24 px accent-tint circle with the number; the title wraps.
.lrow--check > .ic.lrow__checkChecked row: a filled check_circle in the success color; the title wraps.
.list__header / .list__footerText above and below the list, 13 px subtle, indented to the row text.

Variants and sizes

Class or attributeWhen
listWhite with a ring: on the canvas.
list--fillQuiet fill, no ring: inside white cards or on the canvas for a softer group.
lrow--iconRow with a colored icon square; hairline starts at 58 px.
lrow--numNumbered step; top-aligned, wrapping title.
lrow--checkChecked item; top-aligned, wrapping title.

States

StateHow
hover (a, button rows)Tint --bg-tint-strong; the chevron of a linked row moves 2 px right. Only on devices that can hover.
:activeRows that act highlight with --bg-tint-strong while pressed.
selectedShow a trailing check icon in the accent (single choice in a sheet), or use radio cards for a form choice.
current (master-detail)The row whose detail is open beside or under the list: aria-current="true" on the a or button row gives it the accent tint and an accent title. One at a time.
emptyReplace the list with an empty state in the same place.
loadingRows of skeleton shapes inside the same .list.

Motion and microinteractions

  • Linked rows: background over --d-fast (160 ms) on --ease-standard; the chevron leans 2 px on --spring-snappy.
  • Rows that arrive (new results) can use list stagger; rows that leave collapse with height expand. Swipe to reveal actions is swipe actions.
  • No hover lift, no shadows.

Accessibility

  • Use ul/ol with li.lrow for static rows, so the count is announced. For rows that are links or buttons, a div.list of a.lrow / button.lrow is fine; add role="list" and wrap in role="listitem" only if the count matters.
  • Icons and the chevron are aria-hidden="true"; the title is the accessible name of a linked row, so keep it specific.
  • Numbers in .lrow__num are aria-hidden when the list is an <ol> (the order is already announced).
  • A row has one action. Secondary actions go in swipe actions or a dropdown menu, not as extra buttons inside a linked row.

Do and don't

check_circleDo

  • Use a list wherever you were about to stack cards.
  • Keep rows to one action and one or two lines.
  • Name the group with .list__header and explain it with .list__footer.

cancelDon't

  • Wrap rows in li inside a list of links and lose the hairlines; rows must be siblings.
  • Put a button inside a linked row.
  • Add shadows, borders between rows or a custom radius.
