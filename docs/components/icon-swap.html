Icon swap

One glyph turns into another in place: the old one shrinks to half and blurs away while the new one settles on a snappy spring. For icons that say a new state (copied, playing, saved), not for decoration.

Penggunaan

Pakai saat

  • A copy button confirms it worked: content_copy becomes check for 1.6 s (copy button does this).
  • A toggle whose icon names the state: play and pause, bookmark and saved, show and hide password.
  • An icon button whose action changes after use: expand and collapse when the label is not shown.

Pakai yang lain saat

  • Words change (Save, Saved): pakai Text morph.
  • Endorsing with a count and a celebration: pakai Like.
  • Menu icon to close icon: pakai Menu icon. The three bars fold instead of swapping.
  • A chevron that turns with an opening panel: pakai Height expand. Rotate it on the same spring as the panel.
  • A selected state that just fills the icon (tab bar, sidebar): pakai Sliding indicator.

Letaknya. Inside a button: an icon button, a small plain button next to a label, a code block bar. The swap box is 20 px; both glyphs sit in the same grid cell.

Contoh

Anatomi

BagianFungsinya
.swapRequired. aria-hidden inline grid, 20 × 20.
.swap__aRequired. The resting glyph.
.swap__bRequired. The other glyph (add ic--fill for a filled state).
.is-swappedOn .swap: shows swap__b.

Gerak dan mikrointeraksi

  • Leaving glyph: to scale(0.5) with blur(4px) and opacity 0; opacity and blur over --d-fast (160 ms) on --ease-standard, scale on --spring-snappy.
  • Arriving glyph: from the same state to none on --spring-snappy (--d-snappy, 360 ms) while it fades in over --d-fast. Both run at once, so the swap reads as one object changing.
  • Interruption: toggling .is-swapped again mid-swap reverses both glyphs from where they are.
  • Reduced motion: a 120 ms cross-fade with no scale.

Aksesibilitas

  • The swap is aria-hidden. The button carries the meaning: aria-pressed for toggles, and an aria-label that names the action now available ("Pause lecture").
  • Copy announces nothing by itself; when it matters, keep a visible label that changes (data-lds-copy-label) or add a polite status.

Lakukan dan hindari

check_circleLakukan

  • Swap between two glyphs that mean two states of the same thing.
  • Change aria-label or aria-pressed with the glyph.
  • Use ic--fill on swap__b for a filled "on" state.

cancelHindari

  • Rotate or flip icons to swap them.
  • Swap icons on hover.
  • Use the swap for menu to close; use menu icon.

Perilaku dan kode

HTML biasa. CSS only: toggle .is-swapped on .swap. [data-lds-copy] does it for copy buttons (and restores after 1.6 s, with data-lds-copy-label for the visible label).

Terkait

AksiCopy buttonA button that copies a value to the clipboard and confirms in place: the copy icon blurs into a check and the label says "Copied" for 1.6 s. One attribute, `data-lds-copy`, holds the text.AksiIcon buttonA button that shows only an icon: 44 px target, 22 px glyph, round. It always has an `aria-label` and a tooltip with the same words.AksiToggleA button that stays pressed to show a mode is on (bold, pin, mute). Alone it is a `.toggle`; several sit in a `.toggle-group`, either independent (bold, italic, underline) or one at a time (align left, center, right).MikrointeraksiText morphA word changes in place and only the letters that differ move: kept letters slide to their new spot, new ones rise in, leaving ones blur out, and the width springs between the two words. Use it for the result of an action said in words, right where the action happened.
