Check matrix

A grid of checkboxes: things in rows grouped by area, options in columns. The header and the first column stay in place while the box scrolls, and each area has one checkbox per column for all of it.

descriptionView as Markdown

Usage

Use it when

  • Permissions by role: which roles can assign citizen reports, sign permits, export data.
  • Notifications by channel: which events reach email, push and SMS.
  • Any yes or no decision for each pair of two short lists (services per kecamatan office, documents per permit type).

Use something else when

  • A few independent options for one thing: use Checkbox.
  • Settings that take effect at once, one per row: use Switch.
  • Service options compared side by side, read only: use Compare table.
  • Records with values, not choices: use Data table.

Where it goes. Full width of the content column, inside .matrix-box. Give the box a height (--h) when the rows run long so the header stays visible; on phones it scrolls sideways with the first column pinned. Save changes with a button next to it when the choices are costly; otherwise save each change and confirm with a toast.

Examples

Anatomy

PartWhat it is
.matrix-boxRequired. The scroll box: white, ring, large radius. --h sets a max height. Give it tabindex="0", role="region" and an aria-label so keyboard users can scroll it.
table.matrix[data-lds-matrix]Required. A real table with a caption (can be sr-only). --min sets the width under which it scrolls (560 px), --first the first column (220 px), --col each option column (112 px).
thead thThe options (roles, channels), sticky at the top on the quiet fill. .matrix__sub under a name for a count.
tr.matrix__group[data-group]An area heading row: th[scope=rowgroup] and one input[data-lds-matrix-all] per column.
tr[data-group] > th[scope=row]Required. The thing being decided, sticky on the left, with an optional .matrix__sub line.
td > .checkRequired. One checkbox per cell with an aria-label that names both ("Admin: Assign reports"). The whole cell is the target.

Variants and sizes

Class or attributeWhen
--h on .matrix-boxA max height: the box scrolls vertically and the header sticks.
--min / --first / --col on .matrixWidths: below --min the box scrolls sideways with the first column pinned.

States

StateHow
checked / uncheckedThe checkbox tick draws in on change.
mixedAn area box shows the dash (.check.is-mixed, indeterminate) when only some cells in its column are on.
lockeddisabled on a cell (a role nobody may change); say why in the header (a lock icon with a label) or a note.
changed.is-changed on a cell (its td) not saved yet: an accent ring around the box. Clear it after saving.
new column.is-new on the cells of a column just added: they glow on the accent tint once.
hoverThe row tints on pointer devices so the eye can follow it across.

Motion and microinteractions

  • Ticks draw in on --ease-enter (260 ms) and out on --ease-exit (160 ms), as the checkbox does; an area tick runs every box in its column at once, no stagger.
  • A new column glows on the accent tint and fades out over 1600 ms on --ease-standard, once.
  • Row hover tints in 60 ms linear. The sticky header and column do not move.
  • Reduced motion: no glow; ticks still change.

Accessibility

  • It is a real table: options are th[scope=col], things are th[scope=row], areas th[scope=rowgroup], with a caption.
  • Every checkbox has an aria-label that names the row and the column ("Admin: Assign reports"); area boxes say "All Complaints permissions for Admin".
  • The box is focusable with a label so keyboard users can scroll it; Tab moves through the checkboxes in reading order and Space ticks.
  • A locked column says so in words, not only by dimming.

Do and don't

check_circleDo

  • Group rows by area when there are more than eight.
  • Pin the first column and the header; keep column names short.
  • Show what is not saved yet and offer Discard next to Save.

cancelDon't

  • Use switches in the cells; a grid of switches reads as noise.
  • Put more than about eight columns; split the decision instead.
  • Hide locked cells; show them ticked and dimmed so the rule is visible.

Behavior and code

Plain HTML. data-lds-matrix on the table: area boxes tick or clear their column in that area and show mixed, checked or disabled from their cells; a lds:change event (bubbles) carries { input, changed } after each change by a person. After changing cells from code, call matrixRefresh(table).
