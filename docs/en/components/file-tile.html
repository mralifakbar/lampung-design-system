File tile

Files and folders as tiles in a grid: a tinted thumbnail by type (or the picture itself), a two-line name, size and date, a checkbox that appears on hover, focus or while selecting, and a more menu. The tile opens the file; ticking selects it for a bulk action.

Usage

Use it when

  • A file manager or a library where people recognize files by type or picture: course materials, shared drive, uploaded receipts.
  • Picking several files for one action: download 4 files, move 12 photos, delete 2 drafts.

Use something else when

  • Files attached to a form while they upload: use File input. Use the file rows of the file input.
  • Files compared by size, owner and date: use Table. A table scans better than tiles when people sort.
  • A folder hierarchy people browse: use Tree.
  • Photos inside an article or a message: use Thumbnail.

Where it goes. In .file-grid, which fits as many tiles of at least --min (168 px) as the column allows: six to eight on a wide screen, two on a phone. Folders first with .file-tile--folder (a shorter thumbnail), then files. Pair with a selection bar for bulk actions.

Examples

Anatomy

PartWhat it is
.file-gridRequired. The grid (role="list"). Put data-lds-selection="selbarId" on it to wire selection; it gets .is-selecting while anything is ticked, which keeps every checkbox visible.
.file-tileRequired. One file (role="listitem"). Type modifier sets the tone: --folder, --doc, --sheet, --image, --video, --audio, --archive.
.file-tile__openRequired. The <a> (or button) that opens the file: thumbnail, name and meta.
.file-tile__thumbRequired. 104 px tinted area with the type icon (fill style), or an <img> that covers it.
.file-tile__nameRequired. The file name, two lines at most, breaking anywhere so long names never overflow.
.file-tile__metaSize and date, one line, tabular figures.
.check.file-tile__checkThe checkbox top left (input[data-lds-select] with an aria-label).
.icon-btn.file-tile__moreThe more menu top right, with its .menu.

Variants and sizes

Class or attributeWhen
.file-tile--folderFolder: accent tone, 64 px thumbnail.
.file-tile--doc | --sheet | --image | --video | --audio | --archiveFile types, each on its own tone from the --tile-* and series palettes.
.file-grid--compact140 px minimum, 72 px thumbnails.

States

StateHow
hover, focus-withinRing turns --line-strong; checkbox and more button fade in.
selectedThe checkbox is ticked: accent tint and a 1.5 px accent ring on the tile.
.file-grid.is-selectingSet by the selection hook while anything is ticked: all checkboxes show.
touch screensCheckbox and more button always show (no hover to reveal them).

emptyAn empty state in place of the grid, with the upload action.

Motion and microinteractions

  • Press on the tile sinks it to 0.985 in 90 ms and springs back on --spring-snappy.
  • Checkbox and more button fade in over --d-fast and settle from 0.9 on --spring-snappy; the tick draws in as in checkbox.
  • The selection bar rises on --spring-smooth and its count rolls (rolling number).

Accessibility

  • The grid is a role="list" with an aria-label; each tile a listitem.
  • The open link and the checkbox are separate controls: the checkbox has its own aria-label ("Select Budget Q4 2026.xlsx"), the more button names the file too.
  • Checkboxes stay in the tab order even while invisible, and show on focus.
  • Type is in the name (extension) and in the icon, never in color alone.

Do and don't

check_circleDo

  • Sort folders before files, and keep the extension in the name.
  • Use the real picture as the thumbnail for images when you have one.

cancelDon't

  • Truncate names to one line; two lines that break anywhere keep them readable.
  • Make the whole tile a checkbox; opening is the main action.

Behavior and code

Plain HTML. data-lds-selection="selbarId" on the .file-grid wires the input[data-lds-select] checkboxes: .is-selected on each tile, .is-selecting on the grid, the selection bar opens with a rolling count, Shift-click ticks a run, Escape and [data-lds-select-clear] clear. Fires lds:select with { count, items }. Call selectionRefresh(grid) after adding or removing tiles. The more buttons use the menu hook (data-lds-menu).
