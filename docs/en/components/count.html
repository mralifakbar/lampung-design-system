Count

A small red pill with a number of things waiting for the person: unread messages, pending requests. It means "act on these", so use it only for that.

Usage

Use it when

  • Unread or pending items that need the person: 3 new messages, 2 requests to approve.
  • At the trailing end of a navigation row or a settings row that leads to those items.

Use something else when

  • A count inside a tab label: use Tabs. Use .tabs__count, which is quiet grey.
  • A count inside an app shell section heading: use App shell.
  • A state or a type in words: use Badge.
  • A system or connection state: use Status dot.
  • A key figure on a page (credits, score): use Stat row.

Where it goes. At the end of the row or control that leads to the items, before the chevron. In a navigation row, a sidebar item or a menu item. One count per destination; never on content itself.

Examples

Anatomy

PartWhat it is
.countRequired. 18 px pill, danger fill, white 11 px semibold tabular figures, 18 px minimum width so one digit is a circle.
.sr-onlyRecommended. Visually hidden words that say what the number counts.

States

StateHow
zeroRemove the count entirely; never show "0".
over 99Write "99+".

Motion and microinteractions

  • None at rest. When the number changes while visible, a rolling number can slide the digits on --spring-smooth; a count appearing from zero may pop in with lds-pop-in over --d-snappy once.
  • Never pulse or bounce a count to get attention.

Accessibility

  • A bare number means nothing out of context: add visually hidden words inside it (<span class="sr-only"> unread</span>) or include them in the row's accessible name.
  • When a count increases while the person is on the page, announce it politely only if it matters (a role="status" line "2 new messages"); do not make the count itself a live region.
  • Red is not the only signal; the number and the words carry it.

Do and don't

check_circleDo

  • Use it only for things that wait for the person.
  • Clear it as soon as the person has seen the items.
  • Place it inside a flex parent (row, button) so it keeps its pill shape.

cancelDon't

  • Use it for totals ("42 courses"); write the total as text.
  • Show a count on more than two or three destinations at once.
  • Use it as a dot without a number.
