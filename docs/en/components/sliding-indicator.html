Sliding indicator

One marker travels to the chosen option: the segmented thumb, the tab ink, the sidebar highlight, the outline ink, the toolbar highlight. Labels never light up on their own; the single moving element is what tells the eye where the choice went.

Usage

Use it when

  • Choosing one of a few options shown side by side: a segmented control thumb, tabs ink.
  • Showing where you are in a list of places: the sidebar or app shell highlight, the outline ink as sections scroll by.
  • A highlight that follows hover across a row of tools (expanding toolbar).

Use something else when

  • Turning one thing on or off: use Switch.
  • Choosing several options at once: use Chips.
  • The content under the tabs changing: use View swap.
  • Progress through a fixed sequence: use Steps.
  • Pages in a site header (the current link is underlined, not slid): use Top nav.

Where it goes. Behind or under the options it marks, inside their group: seg__thumb as the first child of .seg, tabs__ink first in .tabs, sidebar__hl / shell__hl first in the nav, toc__ink first in .toc, xbar__hl first in .xbar.

Examples

Variants and sizes

Class or attributeWhen
.seg__thumbSegmented control. Width set by data-lds-segmented to one segment; moves by translateX(i * 100%).
.tabs__inkTabs. 2 px line under the selected tab; set by data-lds-tabs.
.sidebar__hl / .shell__hlSidebar and app shell: a tinted pill behind the current item. .shell__hl is placed by data-lds-shell (it watches aria-current).
.toc__inkOutline: a 1.5 px line beside the section in view; data-lds-toc also resizes it to the link height.
.xbar__hlExpanding toolbar: follows hover and focus, travelling once to where the button will end up.

Motion and microinteractions

  • The marker moves with transform on --spring-smooth over --d-smooth (560 ms), no overshoot. When its size changes too (outline, toolbar), height or width use the same spring so both arrive together.
  • Labels change instantly (weight, color) or within --d-fast; they never animate on their own, so there is only one moving thing.
  • Interruption: each new choice sets a new transform; the transition starts from the current position, so rapid clicks or arrow-key presses glide straight to the latest option.
  • Placement on load is instant: set the starting position without a transition (the shell does this for its first frame) so the page does not open with a slide.
  • Theme changes freeze every transition except the segmented thumb, which keeps sliding (.lds-theme-swap).
  • Reduced motion: the marker still moves to its new place, in 120 ms linear, so position stays clear without travel.

Accessibility

  • The indicator is decoration: aria-hidden="true". State lives on the options: aria-pressed (segmented), aria-selected with roving tabindex (tabs), aria-current="page" (navigation), aria-current="true" (outline).
  • Arrow keys move the selection in segmented controls and tabs; navigation lists use Tab.
  • Selection must also show without the marker (weight or color on the label) for high-contrast modes where tints can vanish.

Do and don't

check_circleDo

  • Use one indicator element per group, moved with transform.
  • Let the system hooks place it (data-lds-segmented, data-lds-tabs, data-lds-shell, data-lds-toc).
  • Keep the label change instant and the marker the only travel.

cancelDon't

  • Give each option its own background that fades in and out.
  • Animate left or width with JS frames; set a transform and let CSS spring it.
  • Slide the marker on first render.

Behavior and code

Plain HTML. data-lds-segmented and data-lds-tabs size and move the marker, handle arrow keys and emit lds:change with { index, item }. data-lds-shell places .shell__hl whenever aria-current changes. data-lds-toc moves .toc__ink as sections scroll. .sidebar__hl has no binding of its own: move it yourself or use the app shell.

React. From lampung-design-system/react.

import { Segmented, Tabs } from 'lampung-design-system/react';

<Segmented label="Show grades for" value={range} onChange={setRange}
  options={[{ value: 'week', label: 'This week' }, { value: 'month', label: 'Month' }, { value: 'term', label: 'Term' }]} />
<Tabs label="Course sections" value={tab} onChange={setTab}
  items={[{ value: 'overview', label: 'Overview' }, { value: 'tasks', label: 'Assignments', count: 3 }]} />
