Progress ring

A circular track with the value drawn as an arc and the number in the middle. For compact places and judged scores; say the judgment in words too.

Penggunaan

Pakai saat

  • A score or completion that must fit a square: a quiz result in a card, attendance on a profile, today's goal on a phone home screen.
  • A judged score where the color tells pass, borderline or fail (ring--success|warning|danger), always with words next to it.
  • A task with progress inside a tile or a list row where a bar would be too wide.

Pakai yang lain saat

  • There is room for a line, or the progress belongs to a long task: pakai Progress bar.
  • A level or capacity in segments (storage, strength): pakai Meter.
  • Shares of a whole across several categories: pakai Donut.
  • The number itself is the point, in a row of key figures: pakai Stat row.
  • No measurable value, just waiting: pakai Spinner.

Letaknya. Beside the label it measures: at the start of a card, in a list row before the title, in a results header next to the verdict. 64 px by default; 40 to 48 px in rows; never larger than 120 px (beyond that a stat row or a chart reads better).

Contoh

Anatomi

BagianFungsinya
.ringRequired. 64 x 64 box. Set width and height inline for other sizes; the stroke scales with it.
svg[viewBox="0 0 64 64"]Required. Rotated so the arc starts at 12 o'clock.
circle.ring__trackRequired. cx="32" cy="32" r="27": the full grey track.
circle.ring__valRequired. Same circle with stroke-dasharray="169.6" (the circumference, 2 x pi x 27) and stroke-dashoffset="169.6 x (1 - value)".
.ring__labelOptional number centred over the ring, tabular figures.
.ring--success|warning|dangerColors the arc for a judged score. Default is the accent.

Varian dan ukuran

Kelas atau atributKapan
ringAccent arc. Progress with no judgment.
ring--successPassed, on track.
ring--warningBorderline, needs attention.
ring--dangerFailed or far behind.

Status

StatusCaranya
valuestroke-dashoffset = 169.6 x (1 - value / max) on .ring__val.
emptyOffset 169.6: only the track shows. Write "Not started" next to it.
completeOffset 0. Consider ring--success and a word ("Done").

Gerak dan mikrointeraksi

  • The arc moves through stroke-dashoffset on --ease-inout over --d-considered (480 ms), a transition, so new values retarget from where it is.
  • The React Ring also counts the number up once over 900 ms with an ease-out cubic; with reduced motion it shows the value at once.
  • Under reduced motion the arc change becomes a 120 ms linear change.

Aksesibilitas

  • A score is a picture of a number: role="img" with an aria-label that says the number and the verdict ("Score 86 of 100, passed"), and aria-hidden on the visible label.
  • Live task progress: role="progressbar" with aria-valuemin, aria-valuemax, aria-valuenow and a name.
  • The SVG is aria-hidden="true". Never let the ring color be the only signal; write the verdict next to it.

Lakukan dan hindari

check_circleLakukan

  • Write the verdict in words beside a colored ring.
  • Keep the label to the number; put units and context outside.
  • Use r = 27 and a dasharray of 169.6 so every ring in the product draws the same.

cancelHindari

  • Use a ring for several categories; use a donut.
  • Make it a hero graphic above 120 px.
  • Put a three-digit number in a 40 px ring without shrinking the label.

Perilaku dan kode

HTML biasa. None in plain HTML: set stroke-dashoffset and the label from your code.

React. Dari lampung-design-system/react.

import { Ring } from 'lampung-design-system/react';

<Ring value={86} tone="success" ariaLabel="Score 86 of 100, passed" />
<Ring value={12} max={20} size={44} label="12" ariaLabel="12 of 20 lessons" />

It shows how full, not how far along.GrafikDonutA ring split into up to four segments that show parts of one whole, with the total in the middle and a labelled list beside it. The list carries the numbers; the ring shows proportion at a glance.Tampilan dataStat rowA row of key figures without cards: big tabular numbers with their labels underneath, divided by hairlines.
