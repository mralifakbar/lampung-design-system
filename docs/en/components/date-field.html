Date field

A text field for a date with a calendar button that opens a calendar in a popover. Typing the date always works; the calendar is the helper. Built from existing parts: .control, .control__btn, .popover and .cal.

descriptionView as Markdown

Usage

Use it when

  • People enter one date in a form: a date of birth, a service visit date, a deadline, a payment date.
  • The date is near today and seeing the month helps (booking a visit, choosing a due date).

Use something else when

  • Showing a month of events, or picking a range on the page itself: use Calendar. The .cal component inline, not in a popover.
  • A date far in the past people know by heart (date of birth): use Text field. Typing DD/MM/YYYY is faster than paging back 20 years; keep the calendar button optional.
  • Picking a relative period (this week, this month): use Segmented control. Or chips for presets like "Last 7 days".
  • A time of day only: use Select. A list of half-hour slots.

Where it goes. In a form like any field, about 220 px wide on wide screens (a date never needs the full width). The popover opens below the field, aligned to its right edge. On phones, prefer the native picker (type="date" in a .control) or open the calendar in a sheet.

Anatomy

PartWhat it is
.field / .field__label / .field__helpRequired. Same wrapper as a text field. The helper shows the format ("DD/MM/YYYY").
positioned wrapperRequired. An element with position: relative around the control and the popover, so the popover opens under the field.
.control > inputRequired. Text input, inputmode="numeric", placeholder="DD/MM/YYYY", autocomplete="bday" for birth dates.
.control__btnRequired. The calendar button (calendar_month), aria-label="Choose a date", aria-haspopup="dialog", and data-lds-menu pointing at the popover.
.popover[role=dialog]Required. The floating layer, set to width: auto; padding: 0 and placed under the field.
.calRequired. Month header with previous and next icon buttons, weekday row and .cal__day buttons (.is-today, .is-selected, .is-muted).

States

StateHow
openaria-expanded="true" on the calendar button and .is-open on the popover, set by data-lds-menu.
.cal__day.is-todayAccent text, semibold; add aria-current="date".
.cal__day.is-selectedAccent fill with white text; aria-pressed="true".
.cal__day.is-mutedDays of the next or previous month, faint. Disable days that cannot be chosen (disabled).
.is-invalidOn the .control with aria-invalid, as any field.

Motion and microinteractions

  • The popover grows from the button area: opacity in --d-fast (160 ms) on --ease-enter, scale(0.96) translateY(-4px) to rest on --spring-smooth (560 ms); it leaves in --d-exit (180 ms) on --ease-exit.
  • Days tint on hover in --d-fast and sink to 0.88 on press, springing back on --spring-snappy.
  • Changing month swaps the grid at once; do not slide months, it slows paging through a year.
  • Reduced motion: the popover fades in 120 ms linear without scale.

Accessibility

  • The text input is the real field and works without the calendar: label, format in the helper, validation on blur.
  • The calendar button is a <button type="button"> with aria-label="Choose a date", aria-haspopup="dialog" and aria-expanded.
  • Each day is a button named with the full date ("24 November 2026"); weekday letters are aria-hidden. The month name is aria-live="polite" so paging is announced.
  • data-lds-menu focuses the first button in the popover on open and closes it on Escape or an outside click. Arrow keys between days are not built in: add them (Left, Right by a day; Up, Down by a week) when keyboard use matters.

Do and don't

check_circleDo

  • Accept typed dates in the format shown, and show that format in the helper.
  • Open the calendar on the month of the current value, or today.
  • Disable days that are not allowed and say the rule in the helper.

cancelDon't

  • Make the input read-only so people must use the calendar.
  • Build a new date-picker component; compose these parts.
  • Use the popover calendar for date of birth without allowing typing.

Behavior and code

Plain HTML. No date-field behavior in the system. data-lds-menu="popover-id" on the calendar button opens and closes the popover (outside click, Escape) and focuses its first button; closeMenus() closes it after a pick. Rendering months, paging and writing the value are yours.
