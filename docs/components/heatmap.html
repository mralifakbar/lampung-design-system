Heatmap

A grid of small squares, one per day or slot, shaded in five steps of one hue from empty to most. Shows patterns over many periods (busy weekdays, study streaks) rather than exact values.

Penggunaan

Pakai saat

  • Activity per day over weeks or months: study hours, submissions, logins.
  • Spotting a pattern in two dimensions (weekday by week, hour by weekday) where the exact value of each cell matters less.

Pakai yang lain saat

  • Exact values per category: pakai Bar chart.
  • A trend of one value over time: pakai Line chart.
  • Picking or showing dates: pakai Calendar.
  • How full one capacity is: pakai Meter.

Letaknya. Full width of a .chart-card in a report or profile. The grid has 20 columns and squares scale with the width, so on phones each cell gets small: show the last 10 weeks there, or keep 20 inside a wrapper with overflow-x: auto and a minimum grid width of about 480 px.

Contoh

Anatomi

BagianFungsinya
.hmRequired. A 20 column grid, 3 px gaps. Cells flow row by row, so 7 rows of 20 is weekdays by weeks. role="img" + aria-label.
iRequired. One cell, square, 3 px radius, empty color --bg-skeleton.
.l1 / .l2 / .l3 / .l4Shade steps: --series-1 at 22 %, 45 %, 70 % and 100 %. No class means empty.
scaleRecommended. "Less" to "More" with one cell of each step.

Varian dan ukuran

Kelas atau atributKapan
l1 to l4Four filled steps plus empty: five in all. Map your values to steps with fixed thresholds (1, 2, 3, 4+ hours), not by percentile, so the scale means the same every week.

Status

StatusCaranya
hoverA cell scales to 1.25 on --spring-snappy; its title shows the value.
empty periodAll cells empty is a valid state; say so in the subtitle ("No study logged yet") rather than hiding the grid.
loading, errorSee chart states.

Gerak dan mikrointeraksi

  • Hover: transform: scale(1.25) on --spring-snappy over --d-snappy, back the same way.
  • No entrance animation. Reduced motion: the hover scale becomes a 120 ms change.

Aksesibilitas

  • role="img" on .hm with an aria-label that states the pattern; individual cells are not read.
  • Cell titles are for mouse users only; give the numbers in a .sr-only table or a summary when they matter.
  • One hue, light to dark, so it reads in grayscale and for color-blind readers; the scale legend is aria-hidden because the label carries the meaning.

Lakukan dan hindari

check_circleLakukan

  • Use fixed thresholds for the steps and show the scale.
  • Describe the pattern in the title, subtitle or label.

cancelHindari

  • Use several hues or a rainbow scale.
  • Make cells clickable without making them buttons with names.
  • Change the column count with your own CSS on top of .hm; ask for a column variable in the system instead.
