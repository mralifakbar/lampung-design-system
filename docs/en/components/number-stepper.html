Number stepper

Minus and plus buttons around a small whole number whose digits roll to the new value. For counts people change by one or two, inside a known range.

descriptionView as Markdown

Usage

Use it when

  • A small count with clear bounds: seats to reserve, tickets, people in a group, queue numbers.
  • Most changes are one or two steps from a sensible default.

Use something else when

  • Any amount of money, or values that can be large: use Amount field.
  • A position on a scale (volume, difficulty): use Slider.
  • Choosing between a few fixed counts (1, 2, 3 sessions a week): use Segmented control. Or chips for more than five.
  • Showing a number that changes by itself (live score, count): use Rolling number.

Where it goes. In a form next to its label, or at the end of a list row (a request line, an attendee row). It keeps its own width (about 140 px) and never stretches.

Examples

Anatomy

PartWhat it is
.stepper-fieldRequired. 44 px pill-shaped box, role="group" with aria-labelledby pointing at the label. Carries data-lds-stepper with data-min, data-max, data-value.
button (first)Required. Decrease, with an aria-label ("Fewer seats") and a remove icon. 44 by 44.
.stepper-field__value > .rollRequired. The number, as rolling digits, in an aria-live="polite" span.
button (last)Required. Increase, with an aria-label ("More seats") and an add icon.

States

StateHow
at min / maxThe matching button gets disabled (faint, no pointer events), set by the JS.
hover / activeButtons tint on hover and sink to 0.88 on press, springing back on --spring-snappy.

Motion and microinteractions

  • Each digit is a column of 0 to 9 that slides to its value with transform on --spring-smooth (560 ms). A press during travel retargets from where it is, so fast tapping never queues.
  • Buttons: scale(0.88) on :active, back on --spring-snappy (360 ms); background tint in --d-fast.
  • Reduced motion: the digits move in 120 ms linear, which reads as a change of number without travel.

Accessibility

  • The wrapper is role="group" labelled by the visible label; each button has its own aria-label that names the unit.
  • The value span is aria-live="polite" and setRoll sets its aria-label to the number, so each change is read once.
  • Give both buttons type="button": inside a <form> a bare <button> submits it.
  • There is no hidden input: when the value is part of a form, mirror it into <input type="hidden"> on lds:change.

Do and don't

check_circleDo

  • Start at the most common value and keep the range tight.
  • Name the unit in the button labels ("More seats").

cancelDon't

  • Use a stepper for values above about 50, or for money.
  • Write your own minus/plus pair with a plain number; the rolling digits are the component.

Behavior and code

Plain HTML. data-lds-stepper with data-min (default 0), data-max (default 99) and data-value: the first and last buttons step by one, the .roll updates through setRoll, buttons disable at the bounds, and lds:change fires with { value }. setRoll(el, n) rolls any .roll to a number.
