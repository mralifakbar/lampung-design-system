Chat message

One turn in a conversation. Your words sit in an accent bubble on the right; the assistant answers as plain reading text in the column, with a quiet actions row under it. System lines are centered footnotes.

descriptionView as Markdown

Usage

Use it when

  • Showing what the person sent (msg--me) and what the assistant answered (msg--ai) inside a chat layout.
  • An answer that needs follow-up actions on it: copy, try again, share.
  • A line about the conversation itself (msg--system): a day break, a mode turned on, a file attached.

Use something else when

  • A comment on a document or a review note: use List.
  • A quotation from a source inside an answer: use Quote.
  • A message that tells the person something about the app (saved, offline): use Toast.
  • An event in a history with no conversation: use Timeline.
  • A step the assistant took (searched, read a file): use Tool call.

Where it goes. Inside .chat. msg--me aligns right, up to 88 % of the column (520 px max); msg--ai takes the full reading width (640 px max); msg--system is centered. Meta sits directly under the bubble; actions sit under assistant answers only, aligned with the text.

Examples

Anatomy

PartWhat it is
.msgRequired. The message wrapper: a column with 6 px between bubble, meta and actions.
.msg--me / .msg--ai / .msg--systemRequired. Who is speaking. One per message.
.bubbleRequired for me and ai. The words. Accent fill with a 6 px tail corner for --me; no fill and no padding for --ai, so answers read like the page.
.msg__metaOptional caption line: time, "Edited", "Not sent". Use a timestamp for times.
.msg__actionsOptional row of 36 px icon buttons under an answer: copy (with an icon swap), try again, share.

Variants and sizes

Class or attributeWhen
msg--meWhat the person sent. Right aligned, accent bubble, the bottom right corner tighter (6 px) as the tail.
msg--aiThe assistant answer. Full width plain text; add prose on the bubble when the answer has paragraphs, lists or tables.
msg--systemA centered footnote about the conversation itself.

States

StateHow
arriving (.is-new)Add is-new to a message that arrives while the chat is open: it rises 8 px and fades in once (lds-msg-in). History loaded at once has no is-new and simply appears.
streamingThe bubble is a .stream.is-streaming with a caret; see streaming text. Hide .msg__actions until it ends.
edited"Edited" in .msg__meta.
not sentAn error line under the bubble with Try again (shown here with field__help--error; there is no message-specific error class yet).
copiedThe copy icon swaps to a check for 1.6 s (copy button).

Motion and microinteractions

  • Entrance: lds-msg-in, 8 px rise plus fade, --d-smooth (560 ms) on --spring-smooth. Plays once, only on messages with is-new (sent or received while the chat is open), so a long history never animates as a block.
  • Actions: icon buttons sink to 0.9 on press in 90 ms; copy swaps its glyph with the icon swap recipe (old scales to 0.5 and blurs 4 px, new settles on --spring-snappy).
  • No hover lift, no bubble scaling, no typing dots: the assistant shows work with thinking and text with streaming text.
  • Reduced motion: the entrance is effectively instant (1 ms) and the icon swap cross-fades in 120 ms.

Accessibility

  • Messages are plain elements inside the role="log" column; do not give each one its own live region.
  • If speakers are not obvious from layout alone, add a visually hidden "You said" / "Assistant said" (sr-only) at the start of each message.
  • Every action is an icon button with an aria-label that names the object: "Copy answer", not "Copy".
  • A failed message says so in text ("Not sent. You are offline.") with a Try again button next to it.

Do and don't

check_circleDo

  • Let answers be text in the column; add prose for structure.
  • Show actions under finished answers only.
  • Name sources with citations inside the answer.

cancelDon't

  • Put the assistant in a gray bubble or give it an avatar on every turn.
  • Show a timestamp under every message; prefer day lines and meta on the latest.
  • Color a failed message red without words.

Behavior and code

Plain HTML. None of its own. Copy actions use data-lds-copy (copy button); times use data-lds-time (timestamp); call init() on new messages so both are wired.
