Citation Baru

A small numbered pill after a claim that links to its source: <a class="cite" href="#src-1">1</a>. Used in articles and assistant answers so every fact can be checked.

Penggunaan

Pakai saat

  • An assistant answer or summary states facts drawn from documents: each claim gets a numbered citation to the document it came from.
  • A lesson or report refers to sources listed at the end.

Pakai yang lain saat

  • A link the reader should follow as part of the sentence: pakai Link.
  • Reproducing the words of a source: pakai Quote.
  • A count of items next to a label: pakai Count.
  • A status or category tag: pakai Badge.
  • A preview of a linked page on hover: pakai Hover card.

Letaknya. Directly after the claim, before the period or after it consistently, with no space before it. The numbered sources follow at the end of the text or the message. On phones keep the sources list right below the answer so the jump is short.

Contoh

Anatomi

BagianFungsinya
a.citeRequired. 18 px tall pill on --accent-tint, 11 px semibold tabular number in --accent-text. href points to the source entry (or the source URL).
aria-labelRequired. "Source 1", so it is not read as a bare number.
sources listAn ordered list at the end whose items carry the matching ids. In .prose a plain <ol> is styled already.

Status

StatusCaranya
hoverBackground deepens to --accent-tint-strong over --d-fast.
focusSystem focus ring around the pill.
targetThe source item it points to; use :target in your project CSS or scroll it into view.

Gerak dan mikrointeraksi

  • Only the hover color, over --d-fast. Jumping to the source uses the page's smooth scroll; under reduced motion it jumps.

Aksesibilitas

  • An <a href> with aria-label="Source N"; the visible number alone is meaningless when read.
  • The pill is 18 px tall, under the 44 px touch target. Keep citations spaced apart in text and always provide the full sources list as a second way to reach them.
  • Number sources in order of first appearance and reuse the number for repeat citations.

Lakukan dan hindari

check_circleLakukan

  • Cite every factual claim in an assistant answer that comes from a document.
  • List the sources with titles people recognize.

cancelHindari

  • Cite without a sources list.
  • Use citations as footnotes for asides; write the aside in the text.
  • Put several pills in a row without text between them; list 1, 2 in one sentence instead.
