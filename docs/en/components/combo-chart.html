Combo chart

Bars for what happened in each period and a line for what was expected (a plan, a forecast, last year), on one shared scale, with optional dashed reference lines for fixed thresholds. Drawn from data like the area chart.

Usage

Use it when

  • Actual against plan per month or week: sales against plan, hours against a goal, sign-ups against forecast.
  • Discrete periods (bars) with a continuous expectation running through them (a line).
  • A fixed threshold the reader checks every period: break-even, a limit, a pass mark (a reference line).

Use something else when

  • Two measures in different units on two axes: use Line chart. Two y axes invite false comparisons. Split them into two charts that share the x axis, or index both to 100.
  • Only the actuals, no expectation: use Bar chart.
  • One total against one goal: use Target bar.
  • Volume over many days: use Area chart.

Where it goes. In a chart card, full width for 12 months, half width for a week. Height 200 to 240 px.

Anatomy

PartWhat it is
.chart[data-lds-chart]Required. Same engine as the area chart; series take kind: "bar" or "line".
.chart__barBars per period, rounded on top, 26 px wide at most per series; several bar series group side by side.
.chart__series.is-dashedThe expectation as a dashed line through the bar centers.
.chart__refFixed thresholds, dashed, labelled at the right end.
.chart__bandOn hover or focus the whole period is tinted and the tooltip lists both series.

Motion and microinteractions

  • First view: bars grow from the baseline over --d-smooth (560 ms) on the enter curve; dashed lines fade in.
  • Data changes and toggles tween values and the scale over --d-considered on --ease-inout, from what is on screen.
  • Reduced motion: drawn at once.

Accessibility

  • Same as the area chart: one focusable image with the takeaway as its name, arrow keys announce each period, a hidden table with every value.
  • The expectation is dashed and named in the legend, so it differs by more than color.

Do and don't

check_circleDo

  • Use one scale for both series; they must be in the same unit.
  • Name the expectation for what it is: Plan, Forecast, Last year.

cancelDon't

  • Put a second y axis on the right.
  • Draw the expectation as bars too; the reader then compares four bar heights instead of one bar with a line.

Behavior and code

Plain HTML. Same as the area chart: data-lds-chart or drawChart(el, config).
