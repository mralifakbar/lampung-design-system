Empty state

What a region shows when it has nothing to show yet: an icon, why it is empty, and the one action that fills it.

Penggunaan

Pakai saat

  • A list, table or dashboard section loaded and has no items: no courses yet, nothing due this week.
  • A search or filter returned nothing on a full page of results (say what to change).
  • A first-run screen before the person has created anything.

Pakai yang lain saat

  • The data is still loading: pakai Skeleton.
  • Loading failed: pakai Alert. Use a danger alert with a retry, as in the error data state.
  • No matches inside a command palette: pakai Command palette. Use .cmdk__empty.
  • No matches while typing in a combobox: pakai Combobox. Use .select__empty.
  • A dashboard-level next step for a new account: pakai Spotlight.

Letaknya. In the place the content would occupy: inside the card, the list area or the table box, centred. It replaces the content, not the page header or the filters, so the person can still change the filters. On phones it keeps the same centred stack.

Contoh

Anatomi

BagianFungsinya
.emptyRequired. Centred column with 32/24 px padding and a 6 px gap.
.empty__icon > .icA 56 px rounded square with a hairline and a 28 px icon that names the content.
.empty__titleRequired. Why it is empty, as a fact ("Nothing due this week").
.empty__bodyOne sentence: what will appear here, or what to change. Max 280 px wide.
.btnThe one action that fills it. Secondary by default; primary only on a first-run screen.

Status

StatusCaranya
first runExplains the value and offers the primary action.
clearedAfter the person finished everything ("All caught up"); often no action at all.
no resultsRepeats the query and offers to clear filters; role="status" when it appears after typing.

Gerak dan mikrointeraksi

  • Appears without an entrance when the page loads. When it replaces content in place (the last item was removed), cross-fade over --d-standard (240 ms) on --ease-standard.
  • No looping illustration, no bouncing icon.

Aksesibilitas

  • The icon is decoration (aria-hidden="true").
  • The title is plain text, not a heading, unless the region has no other heading.
  • When it appears in response to a search or filter, give it role="status" so the result is announced.
  • The button names the outcome ("Create a study plan", not "Get started").

Lakukan dan hindari

check_circleLakukan

  • Say why it is empty in the title, and what will appear in the body.
  • Offer exactly one action, or none when nothing helps.
  • Keep the page header and filters visible above it.

cancelHindari

  • Use an empty state while loading.
  • Add generated illustrations or jokes.
  • Offer several actions; pick the one that fills the region.
