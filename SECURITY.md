# Keamanan / Security

**Bahasa Indonesia.** Temukan celah keamanan (misalnya XSS lewat perilaku `js/lds.js`, CLI yang menulis berkas di luar proyek, atau rantai pasok paket)? Jangan buka issue publik. Kirim surel ke **alif@kartadinata.app** dengan langkah reproduksi. Kami membalas dalam tujuh hari dan memberi kredit bila Anda mau.

**English.** Found a vulnerability (for example XSS through a `js/lds.js` behavior, the CLI writing files outside the project, or the package supply chain)? Please do not open a public issue. Email **alif@kartadinata.app** with steps to reproduce. We reply within seven days and credit you if you wish.

Supported versions: the latest minor release of `lampung-design-system`, `lampung-ds` and `lampung_design_system`.
