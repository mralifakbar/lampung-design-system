Tracking follows size

Drag the size. Letters pull together as text grows and open up as it shrinks; leading does the opposite. A single letter-spacing value would be wrong somewhere.

Weights

Three weights do all the work. Bold 700 is reserved for the large title on phone screens.

AaRegular 400 · body, values in lists
AaMedium 500 · labels, badges, tabs
AaSemibold 600 · titles, buttons
AaBold 700 · large title only

Numbers

Anything that updates or lines up in a column uses tabular figures, so digits stop jittering when a value changes.

Reading

Body copy sits between 60 and 72 characters a line. Paragraphs are separated by space, never by indents.
