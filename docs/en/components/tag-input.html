Tag input

A field that turns typed text into removable tags: Enter or comma adds one, Backspace on an empty field removes the last. For several short free values.

Usage

Use it when

  • People enter several short values that are not from a fixed list: topics of interest, keywords for a question, emails to invite.
  • The values are made up by the person, so a list of options cannot cover them.

Use something else when

  • Several choices from a short fixed set (days, subjects): use Chips. All options visible, toggle with one tap.
  • Several choices from a long fixed list: use Checkbox. In a scrolling list or sheet; the system has no multi-select combobox.
  • One value from a long list: use Combobox.
  • One line of text: use Text field.
  • Showing tags or statuses that people do not edit: use Badge.

Where it goes. In a form, full width of its column, with a helper that states the limit. The control grows taller as tags wrap onto new lines.

Examples

Anatomy

PartWhat it is
.control.tagsRequired. The field box, wraps its content and grows from 44 px.
.tagOne value, 28 px, recessed fill, with its text and a remove button.
.tag > buttonRequired per tag. 22 px remove button with a close icon and aria-label="Remove …".
inputRequired. At least 120 px, takes the rest of the line. Named by the label.

States

StateHow
focusAccent edge and halo on the whole box (:focus-within), as any .control.
.is-invalidDanger edge when the typed value is rejected; the text stays in the input.
at the limitDisable the input and say so in the helper ("8 of 8 topics").
tag hoverThe remove button tints on hover.

Motion and microinteractions

  • A new tag pops in with lds-pop-in (scale 0.6 to 1 with fade) on --spring-snappy (360 ms); the input slides along as the line reflows.
  • Removing is immediate, with no exit animation, so Backspace can clear several tags quickly.
  • Reduced motion: the pop becomes a 1 ms appearance.

Accessibility

  • The input is labelled by the field label; the helper says how to add (Enter) and the limit.
  • Each remove button is a <button type="button"> named "Remove Number series". After removing, move focus back to the input.
  • Announce adds and removes in an aria-live="polite" region if the list is long ("Pancasila added, 3 topics").
  • Enter must not submit the form while the input has text; prevent it only in that case.

Do and don't

check_circleDo

  • Accept Enter, comma and paste of a comma-separated list.
  • Trim spaces and ignore duplicates, saying so in the helper.

cancelDon't

  • Use tags for a fixed set of options; that is chips.
  • Put pressed or colored states on tags; they are values, not filters.

Behavior and code

Plain HTML. None in the system. Add a .tag before the input on Enter or comma, remove the last on Backspace in an empty input, and wire each remove button, in your own code.
